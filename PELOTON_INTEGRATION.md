# Peloton Site integration (read-only rollout)

Source URL: `https://raw.githubusercontent.com/Marqesh/Fernandos/main/data/peloton-feed.json`

- `races_2027_targets.json`: 30 authoritative race identities, but only two dates currently verified.
- `data/watch-2027.json`: nightly official-organiser source attempts for all 30.
- `data/latest.json`: two verified 2027 race configurations, including Tour de France stage schedule.
- `build_peloton_feed.py`: strict merger, 2027 year guard, aliases and date safety.
- `data/peloton-feed.json`: one 30-race PUBLIC output, never user records.
- `site_integration.js`: read-only adapter, alias/ID matching, safety checks and status view models.
- `SITE_EDITOR_PROMPT.txt`: exact one-time Site editor instructions.

Automation:

1. **Peloton - Update official race data** runs daily at 07:23 and 19:23 UTC.
2. **Peloton - Watch 2027 startlists** runs daily at 08:41 UTC.
3. **Peloton - Publish Site feed** runs when either of those workflows succeeds and daily at 10:12 UTC as a fallback; can also run manually.

The first public feed must be generated by manually dispatching **Peloton - Publish Site feed** once, or by waiting for its next scheduled/triggered run.

No GitHub tool connected to this chat exposes the private **ChatGPT Sites source editor**. Installing an unrelated Wix/Webflow plugin will not grant access to the existing `.chatgpt.site` project. The user must open the existing Peloton Site editor and paste `SITE_EDITOR_PROMPT.txt`, then review the Site preview and publish it. The GitHub source/feed is prepared for that action.

## Safety and operational notes

- The Site should not write draft picks or scored results from this external feed automatically.
- Race dates `null` are unknown; do not copy 2026 dates to 2027.
- `published` is only accepted for lists validated against the 2027 edition.
- If the organiser is still showing a 2026 list, the 2027 Site displays pending, not those old riders.
- If a latest official update disagrees with a fixed date, mark `change_requires_review`.
- Source failures are not reported as an empty confirmed list.
- Browser fetch requires access to `raw.githubusercontent.com` under Site hosting/CSP rules; test it in Site preview.
